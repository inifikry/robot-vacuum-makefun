# The Robot Vacuum's Best Excuse

Entry for the make.fun bounty
`u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214`.

## What it does

`main.py` writes one line to `/output/entry.txt`: the funniest excuse a
robot vacuum gives for missing a spot, in at most 140 characters.

## The final line

> The dust bunny and I reached an agreement. It stays in the corner, I stay out of the corner.

92 characters, one line, UTF-8.

## Why this line

The judge is a tired homeowner picking the funnier excuse. This line:

- **is an excuse from the vacuum itself** — first person, the vacuum talking;
- **is rooted in the vacuum's own world** — the dust bunny, the corner it
  patrols, the territory it maps;
- **lands on the first read** — the twist is the second sentence: the vacuum
  did not fail to reach the corner, it *negotiated* with what lives there;
- **keeps a straight face** — a small machine calmly reporting a treaty, not
  an owner putting words in its mouth.

## Run it

```sh
python3 main.py
```

It prints the character count and writes `/output/entry.txt`. The output is
deterministic: every run produces the same bytes.
